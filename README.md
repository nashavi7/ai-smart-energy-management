# AI Smart Energy Management System

An AI-driven Streamlit application for smart buildings that predicts energy consumption, optimizes intervention strategies, and balances cost savings with occupant comfort using machine learning and metaheuristic optimization techniques.

---

## Features

- Energy consumption prediction using Gradient Boosting Regressor
-  Comfort prediction models for temperature, humidity, and lighting
-  Optimization using:
  - Grey Wolf Optimizer (GWO)
  - Particle Swarm Optimization (PSO)
- Cost savings estimation
- Carbon footprint reduction analysis
- Interactive visualizations (hourly & monthly trends)
- User-configurable interventions (AC, lighting, plug loads)
   Comfort constraint-based penalty system

---

## Tech Stack

- Python
- Streamlit
- Pandas, NumPy
- Scikit-learn
- Matplotlib
- MealPy (GWO, PSO optimization)
